# Grille d'évaluation /20

| Critère | Points | Attendu |
|---|---:|---|
| AD DS + DNS | 4 | domaine fonctionnel, DNS cohérent, validations correctes |
| OU / groupes / GPO | 3 | structure claire, AGDLP cohérent, ciblage GPO prouvé |
| SMB / NTFS | 2 | moindre privilège, héritage/droits effectifs compris |
| DHCP / intégration client | 2 | scope/options corrects, DNS AD distribué, client validé |
| PowerShell | 3 | contrôles d'existence, erreurs gérées, relançable, rapport lisible |
| Maintenance / Hyper-V | 2 | health-check exploitable et concepts Hyper-V maîtrisés |
| Diagnostic final | 3 | hypothèses, tests, cause racine, correction, validation, prévention |
| Documentation / Git | 1 | preuves claires, commits compréhensibles |

## Bonus qualitatif

Bonus possible pour : second DC, réplication, `-WhatIf`, logs structurés, tests de restauration, mini-lab Hyper-V complet ou script de conformité.
