# Slides

- `T1-Windows-Server-Administration.pptx` : deck PowerPoint éditable, 24 slides, environ **2 h** avec démonstrations.
- `T1-Windows-Server-Administration.pdf` : prévisualisation PDF.
- `speaker-notes.md` : notes et minutage formateur.
- `generate_slides.js` : source PptxGenJS.

## Découpage pour les 8 séances

- **S1 : slides 1 à 16** (~90 min) ;
- **S2 : slides 17 à 24** (~30 min), puis TP1 pendant 60 min.

Pour régénérer :

```bash
npm install pptxgenjs
node generate_slides.js
```
